# Broconnect Biz LLP — Website Package

A responsive multi-page website for GitHub Pages.

## Files
- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services & Pricing
- `projects.html` — Sample Projects (clearly labelled illustrative concepts)
- `contact.html` — Contact form and contact information
- `assets/style.css` — responsive styling, scroll reveals and CSS motion
- `assets/site.js` — mobile menu, reveal animations and email-form handling

## Publish with GitHub Pages
1. Upload all files and the `assets` folder to the root of your repository.
2. Ensure `index.html` is in the repository root (not inside another folder).
3. Open **Settings → Pages** and choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Wait for GitHub Pages to publish the site.

## Images and video
The site uses remote Unsplash image URLs and a remote Pexels MP4 video source, so a network connection is required. If the video provider blocks playback or the clip URL changes, the hero still has a poster/background image; replace the MP4 URL in `index.html` with a video you own or are licensed to use. Do not upload copyrighted media without permission. Motion respects the visitor's reduced-motion preference.
